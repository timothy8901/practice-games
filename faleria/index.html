CONTROLS Click the game window first so it takes keyboard focus.

Movement

  • ←→Walk / run
  • ↑Jump (hold to jump higher)
  • ↓Crouch · climb down · drop through platforms
  • ↑↓Climb ladders
  • ShiftSprint (uses AP)

Action

  • 1–9Select hotbar slot
  • SpaceUse selected item (attack / mine / place / eat)
  • MouseAim · left-click = use at cursor
  • WheelCycle hotbar
  • EInteract (doors, benches, chests, settlers)
  • RReload weapon
  • VV.A.T.S. targeting (slow-mo, costs AP)
  • GThrow grenade
  • HQuick-use Stimpak
  • XToggle background-wall placement mode

Menus

  • PPause menu
  • IInventory & gear (scrap junk here)
  • CCrafting
  • BBuild menu (structures)
  • MSettlement management
  • KCharacter: S.P.E.C.I.A.L. & perks
  • JQuest journal
  • TabWorld map
  • EscClose menu / back

System

  • F5Save game
  • F9Load last save
  • FToggle Pip-Boy lamp
  • NToggle sound
  • -=Zoom out / in
  • F3Debug overlay

Survival

  • Hunger, thirst & rads all tick — eat, drink purified water, use RadAway.
  • Sleep in a bed at night to pass time and heal.
  • Raiders come for your settlement. Build turrets.
