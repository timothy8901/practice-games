# Achievements

Every achievement in **Blob Knight Rumpler** — 76 in all: 12 overall and eight for each of the eight cores. They are tracked as you play, kept in your browser (the app keeps its own), and shown in the game under **Achievements** on the title screen, with progress on the ones you have started.

Edit `achievements/achievements.json` and run `python3 achievements/inline.py` to change the list; this file and the copy inside the game are both generated from it.

## Overall

| Achievement | How you earn it |
|---|---|
| **Take the Field** | Play ten matches. |
| **Champion** | Win twenty-five matches. |
| **Full Armoury** | Win a match with all eight cores. |
| **Hundred Falls** | Knock down a hundred knights. |
| **Survivor** | Clear five rounds in one survival run. |
| **The Gauntlet** | Clear ten rounds in one survival run. |
| **Untouchable** | Win five matches without losing a heart. |
| **Photo Finish** | Win a match in sudden death. |
| **Last Stand** | Win a match after being down to your last heart. |
| **Collector** | Take all twelve buff cards at least once. |
| **Expert Class** | Beat an Expert knight. |
| **Bare-Handed** | Beat a Hard or Expert knight with no card taken. |
